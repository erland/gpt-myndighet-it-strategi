# Release notes – IT-strategen för myndigheter 0.1.0

## Första stabila release

Version 0.1.0 är den första stabila versionen av IT-strategen för myndigheter. Den bygger på 0.1.0-rc.2 och innehåller samtliga pilotjusteringar från steg 31.

## Huvudfunktioner

- research-heavy arbetsflöde för svenska myndigheter
- prioriterad källhierarki och explicit evidens-/spårbarhetsmodell
- analys av uppdrag, styrning, mål, ekonomi, kapacitet, nuläge och förändringstryck
- selektiv IT-omvärldsanalys med skydd mot trenddrivna standardrekommendationer
- strategiska IT-mål, vägval, principer, förflyttningar, konsekvensanalys, färdplan och uppföljning
- fullständig IT-strategi och kort ledningsversion
- mognadsanpassade rekommendationer och public evidence ceiling
- Chat ZIP och Custom GPT från samma canonical beteendekontrakt

## Kvalitet

- 11/11 JSON Schemas
- 7/7 research- och källhanteringstester
- 15/15 strategiska härledningstester
- end-to-end: PASS
- runtime-paritet: 24/24
- blockerande avvikelser: 0

## Kända begränsningar

GPT:n kan bara dra säkra slutsatser från tillgängligt underlag. Brist på offentlig information om intern arkitektur, säkerhetskontroller, systemportfölj eller genomförandekapacitet ska behandlas som informationsgap – inte som belägg för att förmågan saknas. Specifika produkter och detaljlösningar kräver separat analys.
