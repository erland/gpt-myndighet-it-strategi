# Tester för strategisk härledning

Den här sviten verifierar att IT-strategiska slutsatser faktiskt härleds från underlaget och att GPT:n inte hoppar från trend, symptom eller lösningsidé direkt till mål eller vägval.

Kör:

```bash
python3 scripts/run-strategic-derivation-tests.py
```

Testerna är kontraktstester för metod och runtime. De ersätter inte senare end-to-end-utvärderingar med verklig myndighetsresearch.


## Pilotbaserade regressionsfall

SD11–SD15 lades till efter pilotgranskningen och skyddar mot återinförande av mogna förmågor, felaktiga slutsatser från tunn offentlig dokumentation, sammanblandning av teknik i sakuppdraget med intern adoption, nedvärdering av bindande interoperabilitetskrav samt falska diagnoser i säkerhetskänsliga miljöer.
